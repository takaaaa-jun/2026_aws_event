# Dockerを用いた，環境差分をなくした環境構築
- コンテナを作成して，ローカル差分をなくすことで，環境の構築を素早く行うことができる．

## 作成するコンテナ
- 作成するコンテナのサービス名

- db
### 使用するイメージ
- mysql:8.0
### ポート番号
- 3306
### 永続化する場所
- ./dbdata

### コンテナ名
- backend
### 使用するイメージ
- python:3.12
### ポート番号
- 8000
### 永続化する場所
- ./backend_data
